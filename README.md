# 理想気体と実在気体

高校化学「気体の性質」の初学者向け Web 教材です。分子モデルを動かしながら、理想気体と実在気体のちがいを 7 つのステップで学びます。

`index.html` 1 ファイルで動きます（ダブルクリックで開く／校内サーバーや GitHub Pages に置く）。インターネットにつながらない環境では、日本語フォントがパソコンの標準フォントに替わりますが、動作は変わりません。

## ステップ

| | 問い | 分子モデルで見せること |
| --- | --- | --- |
| 1 | 理想気体ってなに？ | 点の分子・分子間力なし。壁にぶつかる勢い＝圧力 |
| 2 | 実在気体は、どこがちがう？ | 理想気体と実在気体（大きさ＋引き合い）を並べる |
| 3 | 分子間力があると、圧力は？ | 予想 → 壁の手前で引きもどされる矢印 → 圧力が小さくなる（約 90） |
| 4 | 分子に体積があると、圧力は？ | 予想 → 入れない場所の表示 → 圧力が大きくなる（約 120） |
| 5 | どんなとき理想気体に近づく？ | 温度・圧力のスライダーと *Z* = *PV*/*nRT* のメーター。高温・低圧で *Z* ≈ 1、低温・高圧で凝縮、高温・高圧で *Z* > 1 |
| 6 | 発展：ファンデルワールスの状態方程式 | 式の 2 つの補正項のスイッチ、*Z*–*P* グラフ（H₂・N₂・CH₄・CO₂、温度可変） |
| 7 | 確認 | 6 問（誤概念「低圧だと分子が動かない」「分子が縮む」を選択肢に入れた） |

どの比較も「分子の数・体積・温度が同じ」条件で、圧力のちがいとして見せています（同じ圧力で体積を比べる説明もありますが、教材の中では混ぜていません）。

## モデルについて

- 分子モデルは 2 次元の分子動力学シミュレーションです（`src/engine.js`）。
  - 分子の体積：かたい円板の弾性衝突
  - 分子間力：接触距離の外側だけにはたらく引力の井戸
  - 温度：速度の再スケール（Berendsen 熱浴）で一定に保つ
- 表示する圧力と *Z* は、全分子の運動から求めた値（ビリアル定理）です。壁への衝突から求めた圧力と一致することを確かめてあり、そちらよりゆらぎが小さいので採用しました。
- 低圧の画面（STEP 5）は、容器が画面より大きくなると「容器の一部」を表示します。分子の大きさを変えずに見せるためです（拡大縮小すると「分子が縮む」と誤解されやすい）。
- STEP 6 のグラフはファンデルワールスの式による計算値です。臨界温度より低いときは、マクスウェルの等面積則で液化の圧力を求めています。*a*, *b* は CRC Handbook of Chemistry and Physics の値です。

## 開発

```sh
node tools/build.mjs          # src/ から index.html を作る
node tools/check-model.js     # モデルが教科書どおりの傾向を示すか確かめる
```

- `src/app.html`：画面と操作
- `src/engine.js`：分子モデル
- `src/vdw.js`：ファンデルワールスの式
